# ADR 0007 — Tips

Status: accepted. Source: docs/legal/tips.md, R-TIP-*.

* Optional, default 0, never pre-selected; capped by `tip_max_tokens` and `tip_max_percent`; quick presets configurable.
* The tip is in tokens on the order, moves to the stand's `tips_payable` token account (not a wallet => can never be spent on goods),
  is excluded from VAT, revenue and Z gross sales (own Z line).
* Payout is an explicit `tips_payout` journal (`POST /tips-payouts`): tokens retired, cash (or bank/donation) paid by a cash desk;
  recipient is a pseudonymous `staff_id` or null for a collective donation. Default policy `collective_donation` (safer for
  volunteers, BE/FR treatment of volunteer tips is [À VALIDER]).
* Event close is refused while tips are payable (`TIPS_OUTSTANDING`) unless explicitly disposed.
* Reports: tips by stand/staff/day, payable vs paid, CSV for payroll. Pools/distribution keys are computed in reports, not in the ledger.
